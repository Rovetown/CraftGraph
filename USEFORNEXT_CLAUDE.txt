DECISIONS MADE FOR STARTUP/WELCOME SCREEN:
==========================================

1. STYLE: IntelliJ-style welcome screen, but embedded in the main window (not a
   separate dialog). It's a STATE of CraftGraphWindow, not a separate window.

2. LIFECYCLE: Welcome screen only on fresh launch (option B).
   Closing a project closes the app -- does NOT return to welcome screen.

3. TOGGLE: A checkbox on the welcome screen + a settings entry to disable it.
   When disabled, the existing "On launch" combo in Settings > General takes over.
   The combo has three options: "Open last project", "Show welcome screen", "Start empty".
   Disabling the welcome screen means the other two options apply.

4. ACTIONS on the welcome screen:
   - Recent projects/folders list (from RecentFiles, clickable)
   - Open Folder button
   - Open Project button
   - New Project button

5. LINKS section: Placeholder entries for GitHub, modding Discord, etc.
   Text-only links for now, icon slots for later.

6. LAYOUT (two-column, IntelliJ-style):
   - Left side (~40%): Recent projects/folders list, each entry showing name + path,
     clickable. Stale entries grayed out.
   - Right side (~60%):
     - App name/logo area at top (placeholder text, icon slot for later)
     - Action buttons stacked: New Project, Open Folder, Open Project
     - Links section below buttons
     - "Don't show on startup" checkbox pinned at bottom

7. IMPLEMENTATION: QStackedWidget in CraftGraphWindow's central area.
   Index 0 = welcome screen widget, Index 1 = editor (splitter with node graph + code editor).
   On launch, show index 0. When a project/folder is opened, switch to index 1.

8. SETTINGS PERSISTENCE: This feature depends on settings persistence (TODO item),
   but the "On launch" combo value can be stored in the config_dir()/settings.json
   alongside recent.json as a minimal persistence step.
